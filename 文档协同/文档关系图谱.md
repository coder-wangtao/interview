## ReactFlow

[ReactFlow](https://reactflow.dev/)要用于创建以下类型的可视化界面：

- **流程图（Flowchart）**
- **工作流编辑器（Workflow Builder）**
- **数据流编辑器（Dataflow Editor）**
- **低代码/无代码平台中的逻辑编辑器**
- **BPMN、UML 编辑器**
- **规则图、状态机图、知识图谱编辑器**
- **AI 管道配置器（如 Prompt Flow、LLM Chain Builder）**

它提供了一整套强大的功能，比如：

- 拖拽连接节点
- 缩放与平移视图
- 自定义节点和边
- 节点自动布局（结合其他库）
- 多选、对齐辅助线、键盘快捷键
- 保存/导出画布状态
- 节点嵌套、分组等（部分功能付费）

有了节点之后，我们还需要连接节点的边(**Edge**)，当然我们可以初始化，并且可控，并且边也应该是可以移动的。并且注意，如果希望能在可视化界面上能实现拖动连接的效果，**最好实现`onConnect`函数，才有连接的效果**

## d3-force

**D3.js** 全名是 **Data-Driven Documents**，是一个使用 JavaScript 操作文档、构建数据可视化的强大库。

- 官网：https://d3js.org/
- 核心理念：**数据驱动 DOM 渲染**，可以通过数据直接控制图表的结构和样式。

D3 并不是一个“全包型”的库，而是一个个功能模块组合而成，比如：

| 模块           | 功能                                                       |
| -------------- | ---------------------------------------------------------- |
| `d3-scale`     | 比例尺（将数据映射到坐标轴）                               |
| `d3-shape`     | 绘制折线图、饼图、雷达图等路径                             |
| `d3-selection` | DOM 选择与绑定                                             |
| `d3-axis`      | 构建坐标轴                                                 |
| `d3-geo`       | 地图投影与路径生成                                         |
| ✅ `d3-force`   | **物理仿真引擎，用于构建力导向图（force-directed graph）** |

**`d3-force` 是用于构建“力导向图”的模块。**

**力导向图（Force-Directed Graph）是什么？**

一种使用“物理引擎”模拟的图布局方式，适合可视化以下场景：

- 节点关系图（如社交网络、知识图谱、依赖图）
- 无层级结构的数据图
- 拓扑图、流程图的自动布局

一般来说，设置力模拟有 4 个步骤：

- 创建**对象数组**(`nodes and edges`)
- 调用`forceSimulation`，传入对象数组 (`nodes`)
- 添加一个或多个`force functions(力函数)`（例如`forceManyBody`, `forceCenter`）
- 设置回调函数, `each tick (每次迭代)`后更新元素的位置。

`d3-force` 内置了很多有用的函数：

- `forceCenter`（用于设置系统的重心）
- `forceManyBody`（用于使元素相互吸引或排斥）
- `forceCollide`（用于防止元素重叠）
- `forceX`和`forceY`（用于将元素吸引到给定点）
- `forceLink`（用于在连接元素之间创建固定距离）

通过`.force()`将**force functions (力函数)**添加到模拟中，第一个参数是定义的 id，第二个参数是`force functions(力函数)`，比如：

```typescript
const simulation = d3
     	.forceSimulation(nodes)
			.force("center", d3.forceCenter(700, 350))
```

我们这里要使用力导向图，那么直接导入d3-force模块即可：

```shell
pmpm add d3-force
```

export function DocGraphDemo() {
  const [nodes, setNodes] = useState<ForceNode[]>(initialNodes);
  const [edges, setEdges] = useState<Edge[]>(initialEdges);
  const onNodesChange = useCallback(
    (changes: NodeChange[]) => setNodes(nodesSnapshot => applyNodeChanges(changes, nodesSnapshot)),
    []
  );

  const onEdgesChange = useCallback(
    (changes: EdgeChange[]) => setEdges(edgesSnapshot => applyEdgeChanges(changes, edgesSnapshot)),
    []

  const onConnect = useCallback((params: Connection) => setEdges(edgesSnapshot => addEdge(params, edgesSnapshot)), []);

    const d3Link = edges.map(edge => ({
      source: edge.source,
      target: edge.target,
      index: edge.id

    const simulation = d3
      .forceSimulation(nodes)
      .force("charge", d3.forceManyBody().strength(-100))
      .force("collide", d3.forceCollide().radius(100))
      .force(
        "link",
        d3
          .forceLink<ForceNode, any>(d3Link)
          .id(d => d.id)
          .distance(200)
          .strength(0.5)
      )
      .force("center", d3.forceCenter(700, 350))
      .alphaDecay(0.01);

    simulation.on("tick", () => {
      setNodes(
        simulation.nodes().map(node => ({
          ...node,
          position: { x: node.x ?? 0, y: node.y ?? 0 }
        }))
      );
    });

    simulation.on("end", () => {
      console.log("end");
    });

    return () => {
      simulation.stop(); // 清理模拟器
    };
  }, []);
  return (
    <div className="h-screen w-full">
      <ReactFlow
        nodeTypes={nodeTypes}
        edgeTypes={edgeTypes}
        nodes={nodes}
        edges={edges}
        onNodesChange={onNodesChange}
        onEdgesChange={onEdgesChange}
        onConnect={onConnect}
      >
        <Background />
        <Controls />
      </ReactFlow>
    </div>
  );
}
